Modern C++
Training & Consulting

I help teams build maintainable C++ software, whether written by humans or generated with AI. My training and consulting focus on orthogonal design and local reasoning for clearer code, easier testing, and faster builds, reducing overall development costs.

Training

Learn when and why to use C++ features, where they fit, and when to avoid them. Practical training in the design decisions that keep your code maintainable, tailored to your team and codebase.

Modern C++

Make informed choices about value semantics, ownership, lifetime, and API design. Evaluate the trade-offs of modern language and library features, and keep code easy to reason about locally.

Effective CMake

Structure maintainable CMake projects around targets and explicit dependencies. Reduce unnecessary rebuilds and simplify testing, installation, and packaging.

Codebase Modernization

Bring the training directly to your codebase. Workshops can combine teaching with real production code: introducing modern C++, improving APIs, simplifying ownership, adopting development tools, or modernizing a build system.

Consulting

More AI-generated code makes maintainability more important.
Clear interfaces, explicit ownership, and testable components help both engineers and AI tools work with your codebase.

Software Design & Refactoring

Improve the structure of existing C++ software while respecting the constraints of a mature codebase. Particular focus on value semantics, ownership, API design, local reasoning, and separation of concerns.

C++ Modernization

Move established C++ codebases forward incrementally. Adopt modern language facilities and engineering practices without requiring a rewrite, using custom clang-tidy checks developed specifically for your codebase to automate repetitive refactoring work.

CMake & Development Tooling

Architecture and modernization of CMake build systems, CTest infrastructure, and workflows using clang-tidy, clang-format, and include-what-you-use.

Code & Architecture Reviews

Independent review of C++ codebases, APIs, architecture, build systems, and development practices, resulting in concrete recommendations and a practical path forward.
